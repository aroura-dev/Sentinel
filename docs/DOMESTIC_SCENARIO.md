# 国内电商物流业务场景

## 业务定位

Sentinel 面向国内电商物流订单异常处置，负责把物流轨迹、订单状态、异常工单、通知触达和 Agent 辅助决策串成闭环。

## 国内物流主链路

```text
下单
  → 仓库出库
  → 快递揽收
  → 干线运输
  → 中转分拨
  → 到达分拨
  → 末端派送
  → 签收
```

## 异常分支

- 超时未揽收；
- 中转或网点长时间滞留；
- 干线运输延误；
- 末端派送失败；
- 买家拒收或包裹退回；
- 丢件、破损；
- SLA 即将超时或已经超时。

## 上下游

- 上游：订单、运单、仓储、承运商轨迹和平台履约任务。
- 下游：异常工单、客服协同、商家工作台、买家通知和 SLA 分析。

## 历史标识兼容

为保持历史和数据库数据兼容，以下标识在源码中继续保留，但业务语义按国内物流解释：

| 历史标识 | 国内业务含义 |
|---|---|
| `EXPORT_CUSTOMS` | 中转分拨 |
| `IMPORT_CUSTOMS` | 到达分拨 |
| `CUSTOMS_DELAY` | 中转延误 |

它们不再代表出口清关、进口清关或海关延误。
